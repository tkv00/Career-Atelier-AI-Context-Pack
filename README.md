# Career Atelier

구독 중인 ChatGPT/Codex와 Claude Code를 로컬에서 연결해, 뉴스 조사부터 자소서 작성·검수까지 이어 주는 개인용 커리어 OS입니다. 우주선 작전실의 다섯 픽셀 에이전트가 서로 결과를 넘기는 과정을 실제 실행 상태에 맞춰 보여 주며, 프롬프트·하네스·자소서 버전·실행 기록은 모두 내 컴퓨터의 SQLite에 저장합니다.

## 실행

필요 조건은 Node.js 22.13 이상, Codex CLI, Claude Code입니다. 두 CLI는 API 키가 아니라 각 구독 계정으로 미리 로그인되어 있어야 합니다.

```bash
npm install
npm run dev
```

브라우저에서 [http://localhost:3000](http://localhost:3000)을 엽니다. `npm run dev`는 웹 화면과 `127.0.0.1:48620`의 로컬 동반 서버를 함께 실행합니다.

macOS에서는 `Start Career Atelier.command`를 더블클릭해도 됩니다. 처음 실행할 때만 의존성을 설치하고 브라우저를 자동으로 엽니다.

## 작업 흐름

1. 루미가 관심 분야의 최신 뉴스를 조사합니다.
2. 모카가 프로필·경험 카드와 맞는 채용공고를 비교합니다.
3. 솔이 Claude Code로 기업과 직무를 공식 자료 중심으로 조사합니다.
4. `초안 전 사용자 승인`이 켜져 있으면 여기서 멈춥니다.
5. 승인 후 뮤즈가 조사 근거와 경험 카드만 사용해 자소서를 작성합니다.
6. 렌즈가 과장·근거 누락·직무 적합성을 검수합니다.
7. 결과와 인계 문서, 자소서 새 버전이 SQLite에 저장됩니다.

모카가 원문 URL까지 확인한 공고는 구조화된 인계 블록으로 반환되어 채용 보드에 자동 등록됩니다. 같은 URL은 새 카드로 중복 생성하지 않고 기존 카드가 갱신됩니다.

Prompt Lab에서는 에이전트별 프롬프트 버전, Codex/Claude Code 배치, 최대 턴, 제한 시간, 출처 규칙, 승인 게이트를 직접 편집할 수 있습니다.

실행 중에는 사무실과 파이프라인의 버튼이 `현재 비서 중단`으로 바뀝니다. 중단된 작업은 실패와 구분되는 `cancelled` 상태로 실행 기록에 남습니다.

## 채용 캘린더

`캘린더`에서는 회사명, 채용 사이트, 지원 직무, 마감일, JD 원문을 직접 등록할 수 있습니다. 모카가 조사해 채용 보드에 저장한 공고를 선택하면 내용을 자동으로 불러오며, 저장된 일정에서 해당 공고와 연결된 자소서 프로젝트를 바로 만들 수 있습니다. 일정은 SQLite와 전체 백업에 함께 저장됩니다.

## 경험 보관함

`경험 보관함`에서는 프로젝트 경험을 상황(S)·과제(T)·행동(A)·결과(R)로 나눠 기록합니다. 성과 수치와 역량 태그를 별도로 저장하고, 검색·필터·완성도 점검을 사용할 수 있습니다. `컨텍스트 복사`를 누르면 선택한 경험만 AI와 자소서에 전달하기 좋은 근거 묶음으로 복사됩니다.

## 다른 컴퓨터에서 이어서 사용

AI 실행은 각 컴퓨터의 로컬 구독 로그인을 사용하고 데이터만 이동합니다.

1. 기존 컴퓨터의 설정에서 `전체 백업 내려받기`를 누릅니다.
2. 새 컴퓨터에 Node.js, Codex CLI, Claude Code를 설치하고 각 구독 계정으로 로그인합니다.
3. Career Atelier 폴더를 복사해 `Start Career Atelier.command` 또는 `npm install && npm run dev`로 실행합니다.
4. 새 컴퓨터의 설정에서 백업 JSON을 선택하고 `비파괴 병합 가져오기`를 누릅니다.

가져오기는 현재 데이터를 삭제하지 않습니다. 같은 자소서의 버전 번호가 충돌하면서 내용이 다르면 새 버전으로 추가하며, 백업 파일에 잘못된 설정이 들어 있어도 API 키와 유료 초과 사용 차단은 그대로 유지됩니다. 로그인 토큰과 API 키는 백업에 포함되지 않습니다.

## 우주선 픽셀 에이전트

루미·모카·솔·뮤즈·렌즈는 통신 분석가, 항로 탐색가, 외계 연구원, 소형 작성 로봇, 검수 로봇으로 시각화됩니다. 각 캐릭터는 배경이 완전히 투명한 4프레임 스프라이트를 사용하며, 단순 이동 대신 타이핑·경로 탐색·자료 판독·초안 작성·근거 검수 동작이 `agent_runs`의 실제 상태와 연결됩니다. 기업조사를 시작하면 관측창의 인공위성이 신호를 보내는 애니메이션도 함께 활성화됩니다.

웹용 작업 스프라이트는 `public/assets/orbit-agent-*-v2.png`에 있습니다. 기존 통합 아틀라스는 이전 버전의 자산 호환성을 위해 보존합니다.

## 추가 API 비용 방지

이 앱의 `Subscription Only Lock`은 다음을 강제합니다.

- 자식 프로세스에서 OpenAI·Anthropic API 키와 클라우드 제공자 환경변수를 제거합니다.
- 실행 직전 Codex가 ChatGPT 구독 로그인인지, Claude Code가 Claude 구독 로그인인지 확인합니다.
- Codex는 읽기 전용·임시 세션으로, Claude Code는 plan 권한으로 실행합니다.
- Claude의 유료 초과 사용 가능 신호를 감지하면 즉시 중단합니다.
- 사용량 한도에 도달하면 API로 우회하지 않고 `waiting_for_reset` 상태로 멈춥니다.
- 서버는 외부 네트워크 인터페이스가 아니라 `127.0.0.1`에만 바인딩됩니다.

여기서 “추가 비용 없음”은 **토큰 단위 API 과금이 없다는 뜻**입니다. 이미 결제 중인 구독 요금은 그대로이며, 구독 플랜의 사용량 한도는 적용됩니다.

## 자소서 편집과 자소설닷컴

문서 보관함에서는 본문을 계속 수정할 수 있고, 공백 포함/제외 글자 수와 목표 글자 수를 동시에 확인합니다. 저장할 때마다 새 버전과 메모가 생성됩니다.

여러 회사의 자소서 프로젝트를 만들면 왼쪽 `ESSAY PROJECT` 선택기에서 전환할 수 있습니다. 각 프로젝트의 버전과 AI 검수 결과는 서로 섞이지 않게 관리됩니다.

`자소설닷컴으로 복사`는 현재 본문을 클립보드에 복사하고 자소설닷컴을 엽니다. 다른 사이트 계정에 직접 저장하는 자동화는 브라우저 보안·로그인·서비스 정책 때문에 포함하지 않았습니다. 열린 편집기에 붙여 넣고 최종 저장만 직접 하면 됩니다.

## 로컬 데이터

- 기본 DB: `local-data/career-atelier.sqlite`
- 실행 작업공간: `local-data/workspaces/`
- 전체 내보내기: 설정 화면의 `전체 JSON 내보내기`
- 저장 항목: 프로필, 경험 카드, 채용공고, 기업 조사, 프롬프트와 버전, 하네스, 자소서와 버전, 실행 이벤트, 인계 산출물

`local-data/`는 Git에 포함되지 않습니다. 백업이 필요하면 SQLite 파일을 복사하거나 JSON 내보내기를 사용하세요.

## 검증

```bash
npm run verify
```

이 명령은 빌드 후 비용이 발생하지 않는 격리된 모의 CLI로 `뉴스 → 채용 → 기업 → 승인 → 작성 → 검수`, 로컬 저장, JSON 내보내기, 비용 잠금을 검증합니다. 실제 로그인 상태는 설정 화면이나 `curl http://127.0.0.1:48620/api/health`에서 확인할 수 있습니다.

## 범위

현재 버전은 개인용 로컬 웹 앱입니다. Supabase나 공개 배포는 사용하지 않습니다. 구독 인증을 브라우저 서버에 넘기지 않고 개인 Codex·Claude Code 로그인을 그대로 사용하는 것이 최우선이기 때문입니다.
