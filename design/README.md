# design/ — 궤도 관제 디자인 시스템

Career Atelier의 UI는 `web/app/globals.css` 한 파일에 토큰 → 프리미티브 →
화면별 규칙 순으로 정리돼 있다. 이 폴더는 그 시스템의 **원본 소스**와
**결정 근거**를 담는다(배포 대상 아님 — Vercel Root Directory가 `web/`이라
여기 있는 10MB 원본 아트는 번들에 들어가지 않는다).

## 세계관과 비율

"우주선 관제실에서 여러 에이전트가 사용자의 취업 미션을 함께 수행한다."
게임 40 : 생산성 도구 60. 우주는 **공간감**으로만 표현하고, 조작부는
조밀하고 명료하게 둔다. 배경이 텍스트와 경쟁하면 그 배경은 틀린 것이다.

## 참고한 외부 원칙

시각 자료·코드·에셋을 복사하지 않고 **규칙만** 가져왔다.

| 출처 | 가져온 규칙 |
|---|---|
| Linear | 1px 헤어라인이 주 구분선. 그림자는 실제로 떠 있는 것(모달·팝오버)에만. |
| Raycast | 강조색은 화면당 한두 곳. 나머지는 무채색 위계로 읽히게 한다. |
| Notion | 본문 가독성이 장식보다 우선. 배경은 절대 텍스트와 경쟁하지 않는다. |
| Teenage Engineering | 라벨은 모노스페이스 대문자, 기능 단위로 그룹핑. |
| galaxy-portfolio류 우주 포트폴리오 | **시각적 방향과 공간 연출만** 참고. 코드·에셋은 쓰지 않고 CSS로 독자 구현. |

## 의도적으로 피한 것 (AI가 찍어낸 티가 나는 패턴)

- 모든 카드에 같은 라운드/같은 그라데이션 반복 → 라운드를 4/8/12/18px로 **의도적으로 다르게** 썼다(칩은 날카롭고 패널은 부드럽다).
- 화면 전체 네온·글로우 → 글로우는 **실제로 살아 있는 것**(실행 중인 에이전트, 데이터 수신 중인 위성)에만 붙인다.
- 장식용 그리드 라인, 의미 없는 네온 테두리 → 넣지 않았다.

## 토큰

`web/app/globals.css`의 `:root` 한 곳에서만 정의한다. 아래 규칙은 전부
토큰만 참조한다 — 컴포넌트에 하드코딩된 hex가 남아 있으면 그건 버그다
(실제로 라이트 테마 잔재 hex가 20곳 넘게 남아 있어 이번에 전부 걷어냈다).

- 색: 배경 3단계 / 표면 4단계 / 선 3단계 / 글자 4단계 / 강조 2계열(앰버=브랜드·주요동작, 시안=데이터·실시간) / 의미색 4종
- 간격: 4px 배수 (`--s1`~`--s12`)
- 라운드: `--r-chip` 4 / `--r-control` 8 / `--r-card` 12 / `--r-panel` 18
- 타이포: 본문 sans, HUD 라벨 mono 대문자 + `--tracking-hud`
- 모션: `--dur-fast` 120ms / `--dur` 200ms / `--dur-slow` 360ms

## 상태는 색만으로 구분하지 않는다

진행 상태(제출/합불), 실행 상태, 질문 출처는 **색 + 점 아이콘 + 텍스트**를
항상 함께 쓴다. 색각 이상 사용자와 흑백 출력에서도 읽혀야 한다.

## 에이전트 스프라이트

`agent-sources/`에 기존 원본 6종과 콤마의 작업 프레임 4장이 있고, `web/scripts/normalize-agent-sprites.mjs`가
이를 배포용으로 굽는다.

```bash
cd web && node scripts/normalize-agent-sprites.mjs
```

**왜 정규화가 필요했나**: 원본은 프레임 크기(429~536px), 캐릭터가 프레임에서
차지하는 비율(70~96%), 바닥 정렬선(상단 여백 8~137px)이 전부 제각각이라
같은 CSS 박스에 넣으면 크기가 눈에 띄게 들쭉날쭉했다. 정규화 후에는 전부
`960x300`(240x300 × 4프레임), 캐릭터 높이 258px, 바닥선 공통이다.
용량도 7.4MB → 372KB로 줄었다(95% 감소).

구현 시 주의:
- 프레임 경계는 **투명한 세로 거터**로 찾는다. 폭을 1/4로 균등 분할하면 시트에 따라 옆 프레임의 홀로그램 조각이 딸려 온다(실제로 겪음).
- 세로 범위와 배율은 **시트 전체에 하나만** 적용한다. 프레임마다 따로 맞추면 홀로그램이 있는 프레임만 커져서 애니메이션 중 캐릭터가 "숨쉬듯" 커졌다 작아진다.

**모션 규칙**: 4프레임 순회 애니메이션은 해당 에이전트가 **실제로 실행 중일
때만** 돈다(`.cloud-agent.active`). 대기 중에는 첫 프레임에 멈춘다 — 장식으로
흔들지 않는다. `prefers-reduced-motion`에서는 작업 프레임에 고정된다.

## 남은 한계 (정직하게)

- 소제목 비서 `콤마`는 역할 정의를 바탕으로 새로 제작했다. 긴 문서 리본을 가슴의 압축 장치로 읽고 빈 제목 트레이에 15자 소제목을 전달하는 실제 작업 동작을 사용한다. 나머지 승무원은 로봇·사람·외계인으로 종족 구성이 섞여 있어 완전히 통일된 아트 디렉션을 원하면 순차적인 원본 재생성이 필요하다.
- 렌즈(검수)는 금색 인간형 드로이드라 실루엣이 잘 알려진 SF 캐릭터와 가깝다. 재생성 시 우선 교체 대상.
