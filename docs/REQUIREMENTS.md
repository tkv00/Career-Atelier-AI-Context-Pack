# 요구사항 대응표

| 요구사항 | 구현 |
|---|---|
| 관심 분야 뉴스 정리 | 루미가 웹 검색 후 출처·날짜·시사점이 포함된 로컬 산출물 저장 |
| 맞춤 채용공고 조사 | 모카가 프로필·경험과 비교하고 확인된 URL을 채용 보드에 자동 등록 |
| Claude Code 기업 조사 | 솔의 기본 실행기를 Claude Code로 고정하고 단독 조사 버튼 제공 |
| 에이전트 간 인계 | 5단계 순차 파이프라인, 공통 컨텍스트, 산출물 라이브러리 |
| 초안 전 사람 승인 | 기업 조사 뒤 승인 게이트에서 일시 중지, 승인 후 작성 재개 |
| 계속 수정 가능한 자소서 | 회사별 프로젝트 선택기, 편집기, 공백 포함/제외 글자 수, 버전 기록 |
| 경험 정리 | 전용 경험 보관함, STAR 편집기, 성과 수치, 역량 태그, 검색·필터, AI 컨텍스트 복사 |
| 자소서 검수 | Claude Code 렌즈 비서의 별도 검수 산출물과 프로젝트별 저장 |
| 자소설닷컴 연결 | 본문 복사와 사이트 열기; 외부 계정 최종 저장은 사용자 수행 |
| Prompt Engineering | 비서별 프롬프트 편집과 불변 버전 저장 |
| Harness Engineering | 비서별 실행기, 턴·시간, 출처 규칙, 승인 규칙, 고정 비용 안전장치 |
| 시각적 컨트롤 | 고양이 사무실, 실제 방향 전환 걷기, 상태별 동작, 움직이는 문서 인계, 파이프라인 노드, 실행 취소 |
| 서로 다른 고양이 | 57프레임 Atelier Cat 아틀라스와 은회색·주황·크림·흰색·턱시도 팔레트 |
| 로컬 저장 | SQLite, JSON 백업 다운로드, 외부 업로드 없음 |
| 다른 컴퓨터 사용 | 기기별 구독 CLI 실행, 전체 JSON 내보내기와 비파괴 병합 가져오기 |
| 추가 API 비용 금지 | API 키 제거, 구독 인증 검사, 유료 초과 사용 차단, 한도 시 대기 |
| 웹 사용 | `localhost:3000`의 반응형 로컬 웹 앱, macOS 더블클릭 실행기 |
| Supabase 대안 | 구독 세션과 개인정보를 외부 서버로 옮기지 않기 위해 로컬 SQLite 선택 |
