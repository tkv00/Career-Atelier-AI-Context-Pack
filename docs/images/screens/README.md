## 찍기 전에 확인할 것

**화면에 실제 이메일이 남지 않게 하세요.** 우측 상단에 로그인한 계정 주소가 표시됩니다. 캡처 후 가리거나, 브라우저 개발자 도구 콘솔에서 아래를 실행해 바꾼 뒤 찍으면 됩니다.

```js
document.querySelectorAll('*').forEach(el => {
  el.childNodes.forEach(n => {
    if (n.nodeType === 3 && n.nodeValue.includes('@'))
      n.nodeValue = n.nodeValue.replace(/[\w.+-]+@[\w.-]+\.\w+/g, 'you@example.com');
  });
});
```

**실제 지원 중인 회사명이 그대로 나가도 괜찮은지** 판단하세요. 공개 리포라면 예시용 회사명으로 바꾸는 편이 낫습니다.

<br>

## 자동으로 찍기

수동 촬영 대신 아래 명령을 쓸 수도 있습니다. 크기·배율이 항상 같고, 이메일도 자동으로 가려집니다.

```bash
npm run shoot-docs
```

Chrome 창이 열리면 **그 창 안에서** 로그인하세요. 메일함도 그 창의 새 탭에서 열어 링크를 클릭해야 합니다. 다른 브라우저에서 링크를 열면 세션이 그쪽에 생겨 촬영용 창은 로그아웃 상태로 남습니다.

한 번 로그인하면 프로필이 저장되므로, 다음부터는 `npm run shoot-docs -- --headless`로 조용히 다시 찍을 수 있습니다.
