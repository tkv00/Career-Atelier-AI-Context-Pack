데이터와 실행을 잇는 구조

웹은 입력과 결과를 관리하고, 내 컴퓨터의 러너는 사용 중인 AI 도구에 일을 맡깁니다. Supabase의 대기 목록이 두 곳을 연결합니다.

웹에서 부탁하고 내 컴퓨터에서 실행합니다

Next.js 웹은 Vercel 또는 localhost에서 실행됩니다. 경험·지원 정보와 첨부 자료는 Supabase 데이터베이스·Storage에 저장합니다. AI에게 맡길 일은 jobs에 추가합니다. 웹 서버는 모델을 직접 부르지 않으며 AI 로그인 정보도 보관하지 않습니다.

러너는 claim_next_job RPC로 대기 중인 일을 하나 가져와 필요한 근거를 읽습니다. JOB / DATA 화살표는 자료가 오가는 방향을 나타냅니다. 실제 요청은 러너가 보냅니다. 첨부 파일은 웹에서 올리고, 로컬 MCP로 가져온 자료는 러너의 가져오기 기능을 함께 씁니다.

결과를 돌려주고 계정을 확인합니다

러너는 AI 도구가 내놓은 답과 근거를 확인해 저장합니다. 진행 과정은 run_events에 남고, 웹은 저장된 결과를 보여줍니다. Supabase Auth와 사용자별 RLS, 기기 승인이 내 자료를 보호합니다. AI 서비스 로그인은 각 도구에서 따로 해야 합니다.

AI 로그인 정보는 내 컴퓨터에 남습니다. 다만 글을 쓰는 데 필요한 자료는 해당 AI 서비스로 전달됩니다. 모델까지 내 컴퓨터에서 돌아가는 것은 아닙니다. GitHub Pages는 작동 방식을 소개하는 정적 사이트이며 실제 작업실은 사용자가 직접 설치해 실행합니다.
