04 · CAREER ATELIER 작동 방식 · 작업 순서

저장한 자료가 다음 일의 바탕이 됩니다

Career Atelier가 기억하는 것은 사용자가 저장한 경험과 초안, 조사 결과입니다. 다음 작업은 필요한 내용을 다시 읽어 그때 쓸 자료를 새로 만듭니다.

남기는 자료와 쓰임

자료저장 위치다음에 쓰는 방법
경험과 지원 정보experience_cards · profiles · job_posts · research_notes비서가 경험과 직무, 기업 정보를 다시 읽습니다.
현재 초안과 수정 요청essay_projects · essay_revision_requests수정할 글과 요청 사항을 읽습니다. 화면에서 저장하지 않은 본문을 바로 보냈다면 그 내용이 우선합니다.
완성된 결과artifacts초안과 인용한 경험 번호, 사용한 AI 서비스, 확인 결과를 보관합니다. 최근 초안이 인용한 경험은 수정할 때 반드시 다시 넣습니다.
작업 기록agent_runs · run_events실행 상태와 오류, 사용량, 고른 근거를 남깁니다. 이 기록을 전부 다음 요청에 넣지는 않습니다.
이번에 읽을 자료로컬 workspaces/<uuid>한 번의 실행에 필요한 파일입니다. 오래 보관하는 업무 자료와 쓰임이 다릅니다.

글을 고칠 때 앞선 근거를 지킵니다

뮤즈는 수정 요청을 받은 순서대로 읽고 현재 초안을 고칩니다. 연결된 기업 조사 자료는 최근 3건까지 가져옵니다. 앞선 초안이 인용한 경험은 반드시 다시 넣습니다. 사람이 직접 쓴 초안처럼 인용 목록이 없다면 저장된 경험을 모두 필수 자료로 봅니다.

필수로 넣을 경험이 정해 둔 분량을 넘으면 일부를 몰래 빼지 않고 멈춥니다. 경험을 나누거나 고정한 선택을 조정해야 다시 실행할 수 있습니다.

지금 구현된 기억의 범위

현재 글쓰기 기능은 벡터 DB, 임베딩 검색, 자동 대화 요약을 쓰지 않습니다. 저장된 자료에서 문항과 맞는 낱말을 찾아 경험을 고릅니다. 한 번의 실행에서 AI가 판단한 내용을 사용자의 사실 기록으로 자동 저장하지도 않습니다.

로컬 백업을 켜면 러너가 실행되는 동안 2시간마다 업무 자료와 첨부 파일 정보를 JSON으로 내보냅니다. Storage에 올린 원본 파일과 로그인 정보, 대기 작업, 자세한 실행 기록은 빠집니다. 데이터 전체를 같은 시점으로 복구하는 백업은 아닙니다.
