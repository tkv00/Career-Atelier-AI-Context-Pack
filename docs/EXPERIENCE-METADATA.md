# 경험 제목과 대표 역량

2026-09-09 공식 자료를 웹에서 조사해 정한 앱 분류다. 외부 기관이 정한 자소서 필수 태그나 점수표는 아니다.

- NCS 직업기초능력: https://ncs.go.kr/mobile/rm08/RM0802List.do?dirSeq=152 — 의사소통, 문제해결, 자기개발, 자원관리, 대인관계, 정보, 기술, 조직이해, 수리, 직업윤리의 10개 영역.
- NACE Career Readiness: https://www.naceweb.org/career-readiness/competencies/career-readiness-defined/ — 의사소통, 비판적 사고, 협업, 리더십, 자기개발, 전문성, 기술 등의 역량과 관찰 가능한 행동 예시.

앱은 수리·정보 영역을 정보분석으로 묶고, 대인관계를 협업·리더십·갈등관리·고객중심으로 나누어 12개로 제한한다. 카드당 최대 3개는 공식 기준이 아니라 탐색 화면의 태그 증식을 줄이기 위한 제품 기준이다. 역량은 본인의 구체적인 행동이 드러나는 원문 인용을 근거로 선택하며, 근거가 부족하면 비워 둔다. 기술명이나 프로젝트명은 별도 태그로 만들지 않는다.

제목은 핵심 대상과 행동 또는 성과 하나를 담은 명사구로 작성한다. 15~30자를 권장하며 공백 포함 40자를 넘길 수 없다. 목록 기호·본문 첫 문장·제목 접두사를 복사하지 않는다. 본문 필드는 요약 과정에서 변경하지 않는다.

웹의 파일·텍스트·엑셀 붙여넣기·Notion 경로는 후보를 합친 후 동일한 로컬 CLI 후처리를 거친다. MCP도 정책에 맞지 않는 제목·태그를 같은 후처리로 정리한다. 이미 짧은 제목과 허용된 태그만 있는 MCP 항목은 유지한다. 웹 직접 입력과 가져오기 수정·저장에도 같은 제목·태그 검증이 적용된다. 모델 호출은 러너에만 있으며 기존 구독 인증·초과 과금 차단을 사용한다.

AI 사용이 꺼져 있거나 정리가 실패하면 웹에서는 원문과 후보를 검토할 수 있으며, 정책에 맞지 않는 후보는 저장할 수 없다. MCP는 정리 실패를 오류로 반환한다. 이전 분석 캐시는 v7로 무효화된다. 제목 후처리 결과는 미리보기와 재저장의 자연키가 달라지지 않도록 사용자 로컬 `~/.career-atelier/metadata-cache/`에 저장하며 읽을 때 원문 근거와 정책을 다시 검증한다.

기존 DB 카드에는 소급 적용하지 않는다. 적용하려면 변경된 러너를 재시작하고 웹 변경을 배포해야 한다.
